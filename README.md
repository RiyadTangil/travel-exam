# travel-exam

A streamlined web application featuring:
- **Authentication & Authorization**: Multi-tenant NextAuth session management, registration, email verification, password reset, and granular RBAC permissions.
- **Task Manager & CRM**: Complete lead pipeline, Kanban board, task queue, scheduling, and conversion.
- **User & Role Management**: Multi-tier user creation, granular permission tree assignment, and developer bypass.
- **Invoice Templates Configuration**: Custom header/footer, digital signatures, watermark controls, and template overrides.
- **Company Profile**: Business settings, logo management, address, and subscription tracking.
- **Admin Panel**: Multi-company oversight, registered agency communication, and platform settings.
